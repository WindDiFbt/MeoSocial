# MeoSocial
MeoSocial is a modern social networking platform designed for connecting people, sharing stories, and building communities. This project is built with Java Spring Boot for the back-end and ReactJS for the front-end, showcasing full-stack development principles.

Features:

- User Profiles: Create and customize user profiles.
- Posts & Interactions: Share updates, photos, and videos; like and comment on posts.
- Messaging: Real-time private messaging between users.
- Groups & Events: Join or create groups and organize events.
- Search & Discover: Find new friends, groups, and trending topics easily.
  
Tech Stack:
- Back-end: Java 17, Spring Boot 3.4.1, Spring Security, Hibernate, MySQL
- Front-end: ReactJS
- Tools: Maven, Postman, Git, IntelliJ IDEA
